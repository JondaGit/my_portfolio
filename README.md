## 🔧 Customization Instructions

### 1. Add Your Photo
- Replace `[Your Photo]` placeholder in `index.html`
- Add your image to `assets/` folder (150x150px recommended)
- Update the image caption

### 2. Update Content
Edit these placeholders in `index.html`:
- `[Your Thesis Title]` - Your bachelor thesis title
- `[Your University Name]` - Your university
- `[Year of Completion]` - Graduation year
- Contact links (email, GitHub, LinkedIn)

### 3. Projects
Each project follows the Unemployables card format:
```html
<div class="project-card">
    <div class="project-card-text-container">
        <div class="subheader-text project-title">Project Name</div>
        <div class="body-text project-card-text">Description...</div>
    </div>
    <div class="project-tags">
        <span class="tag">#Tag1</span>
        <span class="tag">#Tag2</span>
    </div>
</div>
```

## 🚀 Deployment to GitHub Pages

1. **Create repository**: `yourusername.github.io`

3. **Enable GitHub Pages**: Settings > Pages > main branch
