# Portfolio Website Plan

## Structure
- Single-page application using HTML/CSS/JavaScript
- Modern, clean design with responsive layout
- GitHub Pages compatible (static site)

## Sections
1. **Hero Section**: Name, title, brief intro
2. **Projects Showcase**: Cards for each project with details
3. **Bachelor Thesis**: Dedicated section
4. **Skills/Technologies**: Visual representation
5. **Contact**: Links to GitHub, LinkedIn, etc.

## Technical Approach
- Use modern CSS (Flexbox/Grid)
- Minimal JavaScript for interactivity
- Mobile-first responsive design
- Optimized for GitHub Pages deployment

## Files to Create
- index.html - Main page
- style.css - Styling
- script.js - Minimal interactivity
- assets/ - For images/icons

## Design Principles
- Clean typography with professional font
- Consistent color scheme
- Ample white space
- Smooth animations/transitions
- Accessible and SEO-friendly
