Showlifter

SvelteKit Firebase TypeScript Real-time
Overview

Real-time web app focused on enhancing the viewer experience at live sports events and boosting audience engagement. Designed for both event operators and spectators, with separate Client and Admin interfaces.

What it does

The Client part gives spectators a live-updating event view — scores, stats, and highlights pushed in real time. The Admin part allows event operators to manage and broadcast updates during the event. Both parts are built in SvelteKit, with Firebase handling hosting, authentication, and real-time data synchronisation as backend-as-a-service.
