Showlifter

SvelteKit Firebase TypeScript Real-time
Overview

Real-time web app focused on enhancing the viewer experience at live sports events and boosting audience engagement. Designed for both event operators and spectators, with separate Client and Admin interfaces.

Product page: showlifter.com

What it does

The Client part gives spectators an option to participate in live contests and activities, such as quizzes, polls, light shows, and more. The Admin part allows event operators to manage all activities, draw winners, and monitor participation. Both parts are built in SvelteKit, with Firebase handling hosting, authentication, and real-time data synchronisation as backend-as-a-service.

My role

Technical lead driving product and design direction, with hands-on work across architecture, frontend, Firebase backend setup, real-time data flow, deployment, and maintenance.
