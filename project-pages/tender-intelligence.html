Tender Intelligence

Python LLMs Agents RAG FastAPI Docker PostgreSQL On-premise
Overview

Designed and developed an AI platform for automated procurement document analysis and product fulfillment search. The system processes public tender documents, extracts structured requirements using large language models, and matches them against supplier price lists to generate automated bid drafts.

Responsible for the full architecture, development, and on-premise deployment of the system, which is actively used in production and continuously improved.

What it does

Built ingestion pipelines for processing tender documents and supplier price lists in various formats. LLMs extract structured line items, quantities, and specifications from unstructured procurement text. An agentic search layer then finds the best-matching products from supplier catalogues, enabling automated draft creation for bids.
