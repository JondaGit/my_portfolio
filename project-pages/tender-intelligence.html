Tender Intelligence

Python LLMs Agents RAG FastAPI Docker PostgreSQL On-premise
Overview

Designed and developed an AI platform for automated procurement document analysis and product fulfillment search. The system processes public tender documents, extracts structured requirements using large language models, and matches them against supplier price lists to generate automated bid drafts.

Responsible for the full architecture, development, and on-premise deployment of the system, which is actively used in production and continuously improved.

What it does

The platform automates the analysis of procurement documents (tenders) by extracting structured requirements using LLMs. It then matches these requirements against supplier price lists to identify relevant products and generate automated bid drafts. The system includes a dashboard for monitoring tenders, managing supplier data, and reviewing AI-generated insights. It also allows users to search and compare prices of products from predefined distributors, creating custom tenders and participating via human in the loop feedback to continuously improve the AI models.

My role

Solo/full ownership of product architecture, frontend, backend, LLM pipeline design, deployment, monitoring, and ongoing production improvements.

Technical highlights
  • FastAPI backend with PostgreSQL + pgvector
  • LLM-based structured extraction and agentic product search
  • Dashboard for monitoring tenders, relevance scoring, supplier data, and AI-generated outputs
  • On-premise deployment for customer-controlled infrastructure
