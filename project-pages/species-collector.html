Species Collector

Android Java SQLite Offline-first Google Play Freelance
Overview

Offline mobile tool for recording vegetation samples, designed for botanists and field researchers worldwide. Built as a solo freelance project for the Czech Academy of Sciences and published on Google Play.

What it does

Allows botanists to record detailed vegetation samples in the field without requiring an internet connection. All data is stored locally in SQLite and can be exported for analysis. Built entirely in Java for Android, covering the full project lifecycle — from requirements through development, testing, and publishing on Google Play.
