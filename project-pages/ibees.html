Android App  /  Apr 2019 – Aug 2019

iBees

Android Java OpenCV Computer Vision
Overview

Quizzing tool for Czech primary schools, built around a custom real-time matrix barcode detection system. Students scan physical cards with their device camera to answer quiz questions, making classroom interaction more engaging. Developed solo using Java for Android and the OpenCV library.

Development was halted due to lack of government funding, but the working prototype demonstrated reliable real-time barcode recognition.

What it does

The app uses the device camera and a custom OpenCV-based pipeline to detect and decode matrix barcodes in real time — without relying on standard QR code formats. Teachers set up quiz sessions, students scan answer cards, and results are tallied instantly. The custom barcode format allowed physical cards to be printed cheaply for classroom distribution.
